Project 2: Over the Sea

Personally, this was a fun project, I had the materials available and from there I was able to create my own code. The source I used was Parametric Equations and Forces. From there I created my own beach video.
At the beginning of the video I used the bounce code I learned from the previous exercises, I imagined the water droplets that were splashing up when the waves hit the shore from the collision of circles.
The transition to an algorithm, Parametric Equations, created huge ripples that hit the shore, giving the feeling of wanting to spill out of the screen. The original code was a series of rotating lines, I edited and replaced the lines with rectangles and changed the x, y, weight, and height values ​​to 0 and it resized randomly. In addition, the fixed axes x1,x2,y1, and y2 were already fixed, so I edited them there, changing the position of x1 and x2 from sin to tan to get a new coordinate for the project. I wanted a color change, so I added random colors to create variety and increased the stroke weight to make it thicker.
The second algorithm is Forces, I changed the code from falling circles and replaced it with flying, making it suggest evaporation. To be able to change the axis, I changed from 0.1 to -0.1 to create gravity to do the opposite of the existing code. I made my own algorithm loop more and more times and continuously. Besides, the color is also changed to be related to water.
Finally I combined the two algorithms together, creating a final effect like water evaporation and ocean waves crashing on the water surface. I thought this was very interesting, I learned more about creating videos based on captured images and brought them into Adobe Premiere Pro to synthesize all the images.
